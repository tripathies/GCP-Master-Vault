# GCP Learning Roadmap

## Phase 1 — Foundations (Weeks 1–2)
- [ ] Resource hierarchy, projects, billing and quotas.
- [ ] IAM, service accounts and organization policies.
- [ ] VPC, subnets, firewall rules, Cloud NAT and DNS.
- [ ] Create a sandbox and document teardown.

**Checkpoint:** Explain how identity, network and project boundaries work together.

## Phase 2 — Core workloads (Weeks 3–5)
- [ ] Compute Engine and managed instance groups.
- [ ] Cloud Run and API Gateway.
- [ ] Cloud Storage and one database.
- [ ] Load balancing and Cloud Armor.

**Checkpoint:** Deploy and diagram a minimal web workload.

## Phase 3 — Containers, integration and data (Weeks 6–8)
- [ ] GKE and Artifact Registry.
- [ ] Pub/Sub, Eventarc and Workflows.
- [ ] BigQuery and Dataflow basics.
- [ ] Complete a portfolio project.

**Checkpoint:** Explain sync vs async design and failure handling.

## Phase 4 — Enterprise platform (Weeks 9–12)
- [ ] Terraform and reusable modules.
- [ ] CI/CD with Cloud Build/Deploy.
- [ ] Logging, monitoring, audit logs and alerts.
- [ ] Security posture, backup/restore, DR and FinOps.

**Checkpoint:** Present an architecture with trade-offs, threat model, SLO, RTO/RPO, deployment controls and cost model.

Weekly loop: read official docs → draw architecture → deploy the smallest safe lab → validate and test failure → record cost → clean up → practice interview questions.
