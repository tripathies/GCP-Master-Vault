## Practice workflow
- Define data classification, threat model and compliance requirements.
- Apply least-privilege identities and audit-relevant logging.
- Validate key/secret lifecycle and public exposure controls.
- Review detections, alert routing, incident runbooks and evidence retention.
- Test recovery and ensure lab teardown.
